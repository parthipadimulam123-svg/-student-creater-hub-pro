# -student-creater-hub-pro
CreatorHub Pro is a modern JSP app built with JSTL tags and Java EL on a dark Three.js 3D glassmorphism interface. Designed for tech creators, it manages session auth, post creation, and upvotes. Unverified users without LinkedIn complete a 5-question CS quiz (AVL trees, JSP, OpenCV) to unlock applications and link their profile.
